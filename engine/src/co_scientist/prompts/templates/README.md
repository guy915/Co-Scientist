# Prompt templates

These Markdown files are runtime model inputs. Keep instructions, output
contracts, template placeholders and evidence/citation keys intact when editing.
Builders and behavior tests validate their rendering and JSON/schema contracts.

The implementation draws on eight public appendix prompts from Google’s
AI Co-Scientist paper; unpublished prompts are independent reconstructions.
The historical source comparison is preserved at
[revision 9f2ef5e8](https://github.com/guy915/Co-Scientist/blob/9f2ef5e854caf47ceb7a3a9ac90465072c702979/engine/src/co_scientist/prompts/templates/README.md).

Run context, tool instructions, evidence-grounding rules and JSON output
contracts extend the published examples to support this product’s execution.
Do not infer scientific validity or expert agreement from prompt rendering tests.
